# Remote analysis group review

A retained remote `highlight_analysis` conflict can be reviewed as one complete source group.
Its original full quotes are reconstructed against the selected paper's currently registered,
verified PDF. No model, account lookup, remote URL, or global research path participates.

Eligibility requires a valid closed operation and annotation body, a known matching PDF digest,
the matching extracted-text fingerprint, and a nonempty set of quotes that can all be located.
Unknown sources, mismatched versions, incomplete/unlocatable quotes, and lone `ai_highlight`
conflicts remain read-only with a reason. They can still be retained or exported as text.

The displayed preview seals the remote conflict observation and the current analysis, all AI
mark preferences, manual mark layer, parent lifecycle/metadata, and desired/applied PDF state.
Applying uses that displayed base: the existing conflict-resolution operation, reconstructed
companion marks, and local review receipt commit in one transaction. Hidden marks stay hidden;
manual marks remain unchanged. Source, parent and all layers are checked again after conflict
resolution and receipt callbacks. Failure rolls back research, intent, outbox and receipt.

Deleted analysis or companion marks require explicitly choosing the same original paper and
confirming restoration. A remote conflict cannot be moved to another paper. Graph resurrection
uses a new incarnation and keeps tombstone history. Companion singleton conflicts remain retained;
applying a complete analysis does not silently resolve unrelated retained conflicts.

Retries with the same review request return the existing receipt. Another request cannot bypass
pending conflicting work. Previewing, canceling target selection, and choosing Keep current do not
publish companion writes. Readable exports include quote/reason text, excluding local paths and
private generation context. Complete detached backups retain the source bytes and review receipt.

Claim sets remain separate: `paper_claim_sets` generation/sidecar candidates and remote `claims`
content require a future source-aware claim adapter. Generic preview, reattachment and application
stay disabled. Readable claim export uses the closed claim validator and only includes proposed
claim text, caller judgment/status/reason, quoted passage text and location state. It excludes
source/input/generation metadata and does not certify semantic support.

Evidence uses actual isolated two-peer conflict receive/resolve and PDF transfers, real SQLite
rollback/retry and graph revival, detached backup restoration, and Qt repeated-action/target-cancel
fixtures. No production research, external service, provider login or real AI call was used.
Native-device acceptance and the project's full combined check remain separate gates.
