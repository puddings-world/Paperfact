## Fixture admissions, not product relaxations

- Generic local-only test data used date-only note timestamps and an initial new
  list/member used date-only timestamps. Enrolled-v2 correctly rejected them.
  New fixture setup now uses ISO timestamps with timezone; validation was not
  weakened and no real data received an invented timezone. The original audit test
  function AST remains exact; only its local fixture wrapper supplies valid dates.
- A new recreation test assumed a mapped target in an empty receiver. It now creates
  a real graph paper and queries its actual local mapping before controlled external
  delete/recreate. Product lifecycle/mapping checks and all assertions remain strict.
- Review fixtures already contained an active deck; expected current/original values
  now independently read the actual verified prior closure. Active Deck parsing
  supplies known text-style defaults; tests compare its canonical view and retain
  exact raw scientific catalog JSON separately. No maintained test was weakened.

## Required remaining portability

closed content-carrier integration. Root34-case collector/journey selection and
current45-case source/recovered Review selection pass separately; no strict
unknown-protocol guard was removed. Both original full-journey assertions now
reach detached restore, fresh editable adoption and explicit final-path Verify.
See [current recovery actions and limits](recovered-original-scenarios.md).

Initial enrollment finalizes transfer_binding only after publishing final paths.
Do not bind an unpublished stage to guessed final paths or copy stage-native owner
rows across relocation. Keep a closed content-only proposal carrier archive-only
through publication, then explicitly verify/adopt into the final-path receiver
using its real native/binding/target and already owned originals. Stable replay/link
is required to avoid duplicate visible candidates. This remains implementation work.

Full retained unused images/evidence do not imply that every active used-only slide
wire asset or material/source navigation is integrated. Mobile/live history,
provider quality, real auth/quota, physical devices and current full check remain
separate requirements. No account/credential/writer observation travels in list packages.
