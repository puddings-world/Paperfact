## What the reader can do

1. Open retained-work review and select a local or enrolled presentation proposal.
2. Open **Sources and images**. Local proposals now expose the same complete
   evidence/image/original metadata as enrolled proposals, including unused images.
3. Choose an included original version and **Open retained original**.
4. Read it in the existing independent read-only PDF viewer, with pages and zoom.
   Current reading PDF B stays unchanged when the proposal used original A.
5. If bytes are missing/damaged or ownership changed, see a retryable refusal;
   no current PDF, download, AI model or account login substitutes for the source.

This is the retained-proposal review path. Ordinary slide-canvas/source/material
navigation, detached/archive-only originals and every restored virtual proposal
entry still need their own integration/acceptance. The source picker is not an
editable PDF or a publication grant.

## Actual actions and required outcomes

| Situation | Exercise | Observable result |
| --- | --- | --- |

| Corrupt source and retry | Damage bytes, open, restore bytes and explicitly retry; damage again after open. | Failure keeps retry available; restored exact bytes open; the now-invalid cached viewer closes instead of reopening. |
| Late delivery | Hold real source preparation, deselect or close, then release. | No obsolete viewer opens and research SQL remains unchanged. |
| Renderer shutdown | Hold actual fallback rendering, request parent close, try reopening. | The closing viewer never reopens; native resources survive until work drains. |
| Apply plus renderer shutdown | Hold actual Apply and PDF rendering together, close review, release Apply first. | Writer authority retires immediately; no changed active deck/outbox/research while the widget waits for rendering. |
