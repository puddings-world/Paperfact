# 完成修訂後，仍能查看原文：實際驗收

2026-11-02 · `0.5.0.dev` · 隔離整合候選，未發布。

## 本輪解決的使用問題

研究主張套用完成後，原文按鈕也被停用；CLI／MCP重新連線後同樣不能讀原文。
現在查看原文有獨立的唯讀檢查：確認工作區、論文身分、來源歸屬與PDF位元組，
再開引用的A版。閱讀區目前選取的B版維持原樣，不能因此重做已結束的決定。
