# Manual research: prepare, read and recover a workspace copy

Updated2026-11-01. Isolated0.5.0.dev; unreleased. These are local copy/recovery
operations, not a deployed synchronization service or installed-device acceptance.

## What the researcher does

1. Open Workspace and backup -> Prepare workspace copy. Check saved content.
2. Review paper/PDF counts plus additional saved local decks and retained research
   decks. Missing or unsupported content blocks copying rather than disappearing.
3. Choose a new workspace directory and a separate ZIP backup; prepare the copy.
   The old workspace, drafts and provider accounts remain separate. No upload,
   model invocation, service credential or workspace switch is implicit.
4. Explicitly open the prepared copy. Read its current PDF B and edit the saved
   manual deck. The complete original JSON, dormant metadata and original A remain
   retained; a separate four-image research proposal still needs Verify/Apply.
5. FULL-backup that copy, restore detached and explicitly prepare another editable
   copy. All old source/restore folders can be unavailable for receiver byte reads.
