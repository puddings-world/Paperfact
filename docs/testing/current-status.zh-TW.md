## 為什麼有幾千個案例，仍不等於功能完成

- 8,230是先前收集到的Python案例名稱，不是8,230個功能、不是全部通過；之後仍有新增。
- 同一個保存流程，用重試、取消、換論文與換資料庫重跑，就會展開成多個案例。
- 人工說明目前覆蓋整合候選的333個函式／605個案例，其餘仍待整理。
- 終端75%只指當輪執行比例，不能換算版本完成度或剩餘時間。
- 測試時間包含合成資料、PDF、Qt視窗、程序啟動、備份和清理，不是每個按鈕的延遲。
- 多數AI使用固定回覆。原文定位正確，不代表學術解讀正確；真實模型與專家品質另驗收。
- 不同輪次有重疊與不同程式快照，不能把歷史通過數相加。

## 仍擋住發布的事

最後整版檢查在392項通過後遇到1項失敗並停止；該輪前端／手機階段未執行。
引用分析API有局部修復，但「不完整回覆是否自動補跑」及「舊資料筆數是否代表來源核對完成」
的新舊期待仍待對齊。沒有改鬆舊測試，也沒有新的完整通過結果。
另須完成剩餘資料格式、正式服務及登入配對、各平台安裝包，並驗收
**Windows → 離線Apple Silicon Mac → 手機 → 桌機**。
