# 研究主張修訂：改了引句，必須重新核對原文

2026-11-02，隔離 `0.5.0.dev`。**這輪是內部內容處理核心，還沒有新的 App 編輯按鈕。**
私稿保存、恢復後選目標、確認套用與跨裝置完整旅程仍須接上，不能把本輪當成整項功能完成。

| 你之後會做的操作 | 本輪實際演練 | 通過必須證明什麼 |
| --- | --- | --- |
| 改主張與解讀理由 | 用真正測試 PDF 建立原分析，改 assertion／judgment 再重核 | 文字與新的主張 ID 正確；來源仍是 A，產出標明人工修訂，不宣稱學術正確 |
| 換成原文沒有的引句 | 改 quote 後重新定位 | 顯示 missing，沒有舊位置可拿來跳轉 |
| 換成重複出現的句子 | 使用 PDF 中多處相同的句子 | 顯示 ambiguous，不任選一處當唯一答案 |
| 改句子卻留下舊座標 | 保留原 anchor、換另一句 | 顯示 invalid_anchor，不沿用 located 狀態 |
| 開著另一份新版 PDF | 先捕捉 A，再把目前檔案換成 B | 只能產生以 A 為據的待核對內容，不產生套用權限；B 不會被拿來冒充 A |
| 錯拿 B 來核對 A 的草稿 | 使用新版 B 的真正 snapshot 核對舊草稿 | 拒絕，不改原稿 |
| 拿別次分析的草稿來套 | 只改 baseline 中的模型紀錄，再送舊草稿 | 即使 PDF 相同也拒絕，避免混用不同分析 |
| 格式錯誤／太多內容 | 重複 JSON 欄位、無限值、額外權限、空清單、超量主張或引句、超大輸入 | 整筆拒絕，不留下部分「已驗證」結果 |
| 中途取消 | 分別在開始與處理中取消 | 沒有半份修訂產出，原分析與草稿不變 |
| 填外部參考文獻身分 | 加入待核對 DOI／標題 | 身分仍為 unresolved，不會因人工填寫就變成可信引用 |
