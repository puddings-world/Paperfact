## 時間、失敗與限制

時間包含建立衝突、隔離 SQLite、備份恢復、啟動與結束子程序及 Qt 背景工作；不是 App 每次按鈕的延遲。
測試沒有使用日常研究資料庫、真實帳號或付費 AI。

前一輪 13 項中 12 通過、1 失敗：新測試殘留空斷言。已改為比較替換後資料庫的完整邏輯內容，並保留原本的研究不變、舊稿拒絕及無失敗收據檢查。
另在唯讀恢復案例補上官方 SDK 啟動的真正 MCP 子程序，確認讀取不初始化資料庫、寫入拒絕且檔案位元組完全相同。
先做兩項修復驗證（48.89 秒），再執行本輪相關回歸；兩項是重疊案例，不能另加進總數。

這些結果不代表整版通過。最近一次完整檢查仍有引用分析／完成判定的未解差異，後續前端／手機階段未執行。
沒有安裝包、實機 Mac／手機或正式同步驗收。新增外部操作的重試收據尚未逐一驗收所有備份／同儕／接管組合。
位置可核對不代表學術論點受原文支持；其餘論點、螢光筆與簡報接續仍需完成。
